# Atlas Studio Commercial Overview

## Que es

`Atlas Studio` es una plataforma para construir portales cerrados de analitica publica y privada donde:

- los datos se homologan antes de llegar al dashboard;
- las visualizaciones son herramientas de analisis, no solo piezas de exhibicion;
- la metodologia y la auditabilidad viven dentro del mismo portal;
- la arquitectura queda lista para crecer hacia simulacion, optimizacion y modelos de decision.

No es una pagina estatica ni un deck disfrazado de dashboard.  
Es una base operativa para productos de inteligencia aplicada.

## Que resuelve

El problema real no es que falten datos. El problema es que:

- las fuentes oficiales y operativas viven dispersas;
- no usan las mismas claves, cortes ni criterios;
- comparar territorios exige reconstruccion manual;
- la mayoria de los analisis nunca conecta inversion, presion y resultado dentro de una misma capa util.

`Atlas Studio` resuelve esa friccion antes de la interfaz. Primero organiza el sistema de datos, luego expone un tablero utilizable.

## Como funciona

La plataforma trabaja en cinco capas:

1. `Fetch`: descarga fuentes oficiales o institucionales con fecha de corte visible.
2. `Normalize`: homologa geografia, variables y metadata.
3. `Derive`: convierte datos crudos en tasas, shares, indices y scores auditables.
4. `API`: publica payloads listos para matriz, ranking, auditoria y drill.
5. `Portal`: muestra lectura analitica, metodologia, docs y control de acceso.

## Que compra el cliente

El cliente no compra solo un dashboard.

Compra una arquitectura que ya resuelve:

- integracion de fuentes heterogeneas;
- comparabilidad territorial defendible;
- explicabilidad metodologica visible;
- control de acceso para stakeholders;
- una base reutilizable para otros estudios o verticales.

## Diferencial comercial

`Atlas Studio` gana cuando el problema de negocio es:

- comparar unidades territoriales o institucionales;
- vincular inversion con resultado;
- dejar una capa demostrable y presentable para decision;
- acelerar una linea de producto sin empezar de cero cada vez.

Lo dificil aqui no es dibujar graficas.  
Lo dificil es homologar el sistema para que las graficas signifiquen algo.

## Casos de uso

- seguridad publica comparada por estado, ciudad o region;
- gasto publico vs presion operativa;
- salud, investigacion clinica o vigilancia epidemiologica;
- operaciones electorales, territoriales o regulatorias;
- cualquier dominio con multiples fuentes, entidades comparables y necesidad de auditoria.

## Forma de entrega

La entrega comercial puede tomar varias formas:

- portal cerrado con login y trazabilidad;
- demo ejecutiva para decision;
- estudio con metodologia y respaldo tecnico;
- base viva para evolucionar hacia simulacion o asignacion optima.

## Mensaje corto

No estamos vendiendo datos.

Estamos vendiendo una plataforma que ya resolvio la complejidad que normalmente impide que un estudio comparativo llegue a ser util.
